02. Selected Projects

Image Enhancement Platform

A full-stack platform with a plugin-based pipeline architecture for composable image enhancement. It bundles algorithms from CLAHE and Retinex MSR to neural low-light enhancement (Zero-DCE), running pipelines as non-blocking async jobs behind a React UI with side-by-side previews.

FastAPI PyTorch OpenCV React / TS
Source Code -> Live Demo ->

IoT Smart Bike Lock System

Led the design of a dual-ESP32 anti-theft system: the lock unit detects cable cutting via continuity sensing and alerts the bike unit over Bluetooth; the bike unit senses tampering with an ADXL345 accelerometer, tracks GPS, and syncs to Firebase over Wi-Fi. A Firebase Cloud Function listens for alarm events and fires real-time mobile alerts via Pushover.

C++ (ESP32) Firebase IoT
Source Code ->

Hand Landmark Detection

An end-to-end pipeline for detecting 47 anatomical hand keypoints. Built on MMPose with an HRNet-W32 backbone, I compared a heatmap baseline against a coordinate-classification (SimCC) head — the SimCC model reached 0.94 COCO AP with notably lower end-point error.

PyTorch MMPose HRNet / SimCC
